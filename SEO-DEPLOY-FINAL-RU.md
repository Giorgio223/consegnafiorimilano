# SEO-обновление — 20 ноября 2026

## Что изменено

- `app/page.tsx`: добавлен self-canonical для главной `/` и полный кластер `hreflang` для 6 языков, включая `x-default`.
- `app/layout.tsx`: удалены глобальные языковые alternate-ссылки. Они ошибочно наследовались страницами, для которых нет реальных переводов (например, `/privacy-policy`, `/servizi/...`). На переводных страницах (категории, товары и `/en`–`/ru`) языковые альтернативы уже заданы непосредственно в metadata страниц и сохранены.
- `components/CookieConsent.tsx`: добавлены переводы интерфейса cookie-согласия на немецкий, испанский и французский. Логика согласия Google Analytics/Ads не изменялась.
- `proxy.ts`: уточнён устаревший комментарий. Существующие рабочие 301-переадресации, заголовки локали и SSL-исключения сохранены.

## Что намеренно не изменяли

- Stripe Checkout, админ-панель, статусы заказов и корзину.
- Канонический домен `https://consegnafiorimilano.it` без www.
- 25 языковых доменов и исключения `flowersmilan.co`, `flowersmilan.it`, `flowersmilan.com`, `consegnah24.it`.
- `vercel.json` и существующий `sitemap.xml`: локализованные кластеры уже есть. Нельзя создавать `hreflang` для несуществующих переводов.

## Как задеплоить через GitHub Desktop

1. Сделайте резервную копию текущей локальной папки GitHub, особенно `.env.local` (если есть). Не добавляйте секреты в Git.
2. Распакуйте архив и скопируйте **содержимое** `consegnafiorimilano-main` поверх файлов вашего локального клона `consegnafiorimilano`, сохраняя папку `.git` и локальные `.env.local`.
3. В корне клона выполните `npm ci` и `npm run build`. Не используйте `npm audit fix --force` без отдельного тестирования.
4. В GitHub Desktop проверьте список изменений, сделайте `Commit to main`, затем `Push origin`.
5. В Vercel проверьте успешный Production `Ready` и откройте `/`, `/en`, `/de`, `/es`, `/fr`, `/ru`.
6. Проверьте исходный HTML страниц: self-canonical, `hreflang` на всех шести переводах и `x-default`. Проверяйте также `/privacy-policy`: **не должно** быть ложных переводных ссылок.
7. В Google Search Console уже отправленный `https://consegnafiorimilano.it/sitemap.xml` не дублируйте. Проверьте Coverage/Indexing и поисковые запросы после обновления данных.

## Важные ограничения

- Успешная сборка не гарантирует индексацию и высокие позиции Google.
- Переводные юридические страницы для `de/es/fr` в исходном проекте не созданы. Не следует рекламировать их как `hreflang`-альтернативы существующих страниц.
- `www`-варианты сторонних доменов должны быть добавлены отдельно в Vercel и иметь DNS/HTTPS, если вы хотите их использовать.
