## Перед деплоем

1. Распакуйте архив и скопируйте содержимое корневой папки в существующий локальный репозиторий, сохранив .git и .env.local.
2. Выполните npm ci и npm run build.
3. При успешной сборке Commit → Push origin.
4. После статуса Vercel Ready проверьте /recensioni, /en/recensioni, /fr/recensioni, /ru/recensioni, /chi-siamo и корзину.

Отзывы публикуются на основании заявления владельца об их происхождении из WhatsApp; убедитесь в наличии согласия на публикацию.
