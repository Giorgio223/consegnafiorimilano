## Установка через GitHub Desktop
1. Распакуйте ZIP и откройте `consegnafiorimilano-main`.
2. В GitHub Desktop откройте ваш локальный репозиторий → Repository → Show in Explorer.
3. Скопируйте **содержимое** распакованной папки в корень локального репозитория **с заменой**. НЕ удаляйте `.git` и `.env.local`.
4. В терминале локального репозитория запустите `npm ci` и `npm run build`.
5. Когда сборка успешна: commit → push origin; проверьте Vercel → Production Ready.
6. На сайте протестируйте `/`, `/fr`, `/de`, `/es`, `/en`, `/ru`, `/chi-siamo`, `/recensioni`, `/fr/chi-siamo`, `/fr/recensioni`, заказ и Stripe в тестовом режиме, картинки WebP.
