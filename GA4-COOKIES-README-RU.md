# Проверка Google Analytics и Cookie Consent

## Установка

В Vercel в Production добавьте NEXT_PUBLIC_GA4_ID=G-MK9JGVVJMY. После изменения переменных сделайте Redeploy. Не добавляйте второй Google tag вручную.

## Тест

1. В новом окне инкогнито откройте сайт, подключив Tag Assistant.
2. В Tag Assistant откройте первую запись Consent: все 4 статуса должны быть denied.
3. На сайте нажмите Accetta tutti. Должно появиться consent update с granted для analytics_storage и рекламы.
4. Проверьте отправленные обращения: page_view должен отправляться в G-MK9JGVVJMY.
5. Перейдите на страницу букета и проверьте новый page_view; GA4 Realtime может запаздывать.
6. Нажмите постоянную кнопку Preferenze cookie слева снизу, отключите статистику, сохраните. В новом сеансе Google tag не должен загружаться без разрешения.

## Что изменено

Вместо позднего React consent default установлены синхронные consent mode v2 defaults в head, до Google tag. При выборе отправляется consent update; тег загружается только после разрешения. Добавлена постоянная нижняя кнопка управления согласием. Основная панель увеличена.

## Осторожно

Google Analytics работает только после согласия пользователя, поэтому Realtime не обязан считать посетителей, отказавшихся от cookies. Наличие тега в Tag Assistant не гарантирует появления page_view: проверяйте отправленные обращения. GA4 не заменяет юридическую проверку privacy policy. Проверьте полноценную сборку и тестовый заказ перед публикацией.
